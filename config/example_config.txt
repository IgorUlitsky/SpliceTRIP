### FASTQ_MAPS
# name<TAB>path_prefix<TAB>r1_suffix<TAB>r2_suffix<TAB>mapName<TAB>contamination_batch(optional)
#
# One row per Map-mode (DNA) fastq sample. path_prefix is the path *including* the sample
# name, WITHOUT the R1/R2 suffix, e.g. for
#   /home/projects/ulitsky/igoru/data/human/TRIP/run5/Map_CPA_noP_pool1_rep2_S164_R1_001.fastq.gz
# path_prefix = /home/projects/ulitsky/igoru/data/human/TRIP/run5/Map_CPA_noP_pool1_rep2_S164
# and r1_suffix/r2_suffix = _R1_001.fastq.gz / _R2_001.fastq.gz
#
# mapName is which construct this sample's barcodes get combined into at stage 06 (every
# row sharing a mapName is combined into one genuine-barcode map) -- it also doubles as the
# stage 05 contamination group, since here the two are the same thing: contamination is
# checked "does this barcode look real in construct X, or does it look like it leaked in
# from some OTHER construct Y that was sequenced alongside it".
#
# contamination_batch (6th column, optional): stage 05 runs filterContaminants once PER
# DISTINCT batch value, comparing only samples that share a batch (real index-hopping
# contamination can only happen between samples multiplexed on the same physical
# sequencing run, so this matches the real historical practice of one fileList per run
# directory, e.g. run3.txt/run5.txt). Leave blank to put every sample in a single implicit
# "default" batch (fine for a config that only spans one run).
